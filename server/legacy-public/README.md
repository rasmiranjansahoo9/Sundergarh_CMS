## Production requirements
This package is a front-end starter. For deployment as an actual government portal, connect:
1. Secure backend/API (Node.js/PHP/Laravel/.NET/etc.)
2. PostgreSQL/MySQL database
3. Authentication + RBAC
4. Secure file/PDF storage
5. Real CMS CRUD
6. Search indexing
7. Audit logs
8. CAPTCHA / spam protection for public forms
9. HTTPS, security headers and backup strategy
10. Official Odisha/Forest Department branding and verified content
11. Approved contact details, notices, tenders and RTI documents
12. Accessibility testing and government web guidelines compliance

Do not use the sample statistics, contact details or sample notices as official departmental information.
